User Guide & Feature Reference

1. Quick Overview & Supported Scripts

The Offline Transliteration Tool converts text between 17 Indian and Roman scripts completely offline: Devanagari, IAST, ITRANS, Bengali, Odia (Oriya), Gujarati, Gurmukhi, Kannada, Malayalam, Tamil, Telugu, Harvard-Kyoto (HK), SLP1, Velthuis, WX, Kolkata (National Library), and ITRANS (Dravidian).

2. Top Header & Workspace Controls

  • Live Typing (Toggle): When checked, the Output box updates automatically as you type or paste. Uncheck it when working with very large documents to transliterate manually using the green ➠ Run button in the center.
  • Sync Scroll (Toggle): Locks the vertical scrollbars of the Input and Output boxes together so parallel verses stay aligned as you scroll.
  • Font Size (A- / A+): Adjusts the workspace text size between 12px and 36px. Also scales the font size used when copying rich text into Microsoft Word.
  • Character Map: Opens a side-by-side visual lookup chart for Vowels, Marks, Consonants, and Symbols between your currently selected Input and Output scripts.
  • Swap Button (⇄ in Center): Swaps the active Input and Output scripts along with their text boxes for instant reverse transliteration.
  • Paste / Clear / Copy: Quickly paste clipboard text into Input, clear both panes, or copy the text. The green Copy buttons export both plain text and Microsoft Word Rich Text (preserving your chosen Indic and Roman fonts).
  • Save .txt: Opens a Windows Save As dialog to save your transliterated output as a UTF-8 .txt file.
  • Search (Ctrl + F): Press Ctrl + F anywhere in the app to search and highlight words across your Input and Output panes.

3. Dual-Script Output (Interleaved Stanzas or Lines)

You can generate two output scripts simultaneously—ideal for study books, stotra handouts, and bilingual proofreading:

  • Preset (Devanagari + IAST): Select Devanagari + IAST directly in the Output dropdown.
  • Custom (+ 2nd Script): Check the + 2nd Script: box in the Output toolbar and pick any of the 17 scripts from the secondary dropdown (for example, Odia + IAST or Devanagari + Malayalam).

4. Settings & Preferences Explained (Gear Icon ⚙)

  • Display 'Auto-Detect Script' in Input Box: When set to Yes, adds an Auto-Detect Script option to the Input dropdown that automatically identifies whether pasted text is Devanagari, Bengali, Odia, IAST, ITRANS, SLP1, etc., and displays a badge showing the detected script.
  • Devanagari / Indic Ending Mode (Schwa Syncope):
    • Sanskrit Style (Default): Final consonants without a vowel retain an explicit virāma/halant (e.g., ajay ➔ अजय्, rAm ➔ राम्).
    • Hindi / Marathi Style: Applies schwa syncope so final consonants drop the virāma (e.g., ajay ➔ अजय, rAm ➔ राम).
  • Dual-Script Output Grouping:
    • Stanza-by-Stanza (Default): Groups paragraphs separated by a blank line—printing the full stanza in the 1st script followed immediately by the full stanza in the 2nd script.
    • Line-by-Line: Interleaves every single line in the 1st script with its corresponding line in the 2nd script.
  • Word Export & Rich-Text Copy Fonts: Select your preferred font for Brahmic / Indic Scripts (e.g., Mangal, Nirmala UI, Siddhanta, Sanskrit 2003) and Roman / Diacritic Scripts (e.g., Calibri, Times New Roman, Gentium Plus). When you click Copy and paste into Microsoft Word, each line is automatically formatted with the matching font!
  • Choose Visible Scripts: Customize which of the 17 scripts appear in your Input and Output dropdown menus to keep your workspace clutter-free. Use Select All 17 or Reset Defaults anytime.

5. Special Transliteration Syntax & Escape Rules

1. Pause Transliteration (##): Type ## to disable transliteration for a phrase and ## again to resume:

bhagavad ##(divine one)## gItA ➔ भगवद् (divine one) गीता

2. Escape a Single Character (\): Place \ before any character in ITRANS to keep it untransliterated:

bhagavad . gItA\. ➔ भगवद् । गीता.

3. Break Up Conjunct Consonants ({} or _): In ITRANS, use {} for a zero-width joiner or _ to separate adjacent vowels:

kShetra vs k{}Shetra ➔ क्षेत्र vs क्‍षेत्र
barau vs bara_u ➔ बरौ vs बरउ

4. Force Virāma (.h): In ITRANS, typing .h after a consonant explicitly marks a virāma (्).
